Preflight check

Checks that every hole image named in js/holes-data.js actually loads from where the site expects it. Run it locally before you push, then again on the live URL after deploying — file names are case-sensitive on GitHub Pages but not on Windows, so a file that works on your machine can still 404 once published. That's the failure this page exists to catch.
