UPDATE PACKAGE — folder layout
========================================

CODE ONLY. No holes-data.js and no hole images, so uploading this cannot
touch your data.

This package is for a repository laid out like:
  index.html, admin.html, css/style.css, js/app.js, images/holes/*.jpg

Images will be saved to: images/holes/

UPLOAD
  Unzip. In your repo: Add file -> Upload files, drag the CONTENTS in
  (keeping the folders), commit. Then reload the admin with Ctrl-Shift-R.

VERIFY BEFORE SAVING
  In "Save to GitHub", click "Show what will be saved". Check that:
    "This build saves images to" matches "Your data stores images in"
  If a red warning appears saying the wrong build is deployed, stop --
  you have the other layout's package.
