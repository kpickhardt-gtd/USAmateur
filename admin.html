Stage 1 — make the hole image

Place the tee box and the top of the green on the satellite map. Each pin appears as soon as you click. The view rotates and scales itself to the tee→green line, so what you see is what the capture produces. Shift-drag (or two-finger twist) to spin the imagery while hunting for the hole.

Doglegs: add shot points so the centre line follows the fairway instead of cutting the corner. S1 is where the tee shot lands; par 5s often want an S2 as well. The line runs Tee → S1 → S2 → Green, and hole yardage is measured along it.

Stage 2 — place marshal stations

This hole has no image yet. Go to stage 1 and capture (or upload) one first — marshal stations are placed on the image, not on the satellite map.

Click the image to drop a station; drag its numbered pin to fine-tune. Positions are stored relative to the hole's own centre line — distance walked from the tee, and yards left or right of the fairway — so they survive replacing the image. Drag T, G or any S marker to reshape the line; stations follow it.

    Save to GitHub

    Create a fine-grained personal access token at github.com → Settings → Developer settings → Personal access tokens, limited to this one repository, with Contents: Read and write. It is stored in this browser only — never written into any file this tool produces, and never committed. Anyone holding it can write to the repo, so don't tick "remember" on a shared computer.

    Marshal pages are unaffected by any of this: they stay plain static files and never call an API, so they keep working on poor course signal.

    Manual backup

    Run the preflight check before publishing — it confirms every hole image actually loads from where the data says it is.

    Captured images download to your computer — save them into images/holes/ in the repo. The data itself only reaches the live site when you export holes-data.js and commit it.
